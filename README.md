## 📖 项目简介

在水果零售场景中，整箱水果（如榴莲）常常需要拆开果皮与果肉，重新分装成若干份出售。为了**保证总售价不变**，就需要根据每份的实际重量，重新计算单价与每份售价。

本项目正是解决这一痛点的轻量级工具：

> **输入原始总价与每份重量，自动得出重包装后的单价和每份售价。**

无需手工按计算器，避免算错、算乱，一步到位。

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 🔀 **两种分装模式** | 支持「4 颗分 3 份」与「3 颗分 2 份」，一键切换 |
| 💰 **实时总价计算** | 输入单价与总重量，自动显示原始总价及计算过程 |
| ⚖️ **逐份价格计算** | 输入每份重量，同行即时显示该份对应售价 |
| 📊 **重包装后单价** | 自动汇总总重量，并按总价不变原则算出新单价 |
| 🔄 **重新计算** | 一键保存本次结果并清空输入，方便连续处理多批货 |
| 📝 **本地历史记录** | 自动记录每次计算结果（含时间、每份明细），最多保留 20 条，可一键清空 |
| 🔢 **数字键盘输入** | 输入框自动唤起数字键盘，仅允许数字与小数点 |
| 📤 **分享转发** | 支持转发给好友、分享到朋友圈 |

## 🧮 计算规则

### 基础公式

```
原始总价       = 原始总重量 × 每斤单价
重包装后总重量 = 各份重量之和
重包装后单价   = 原始总价 ÷ 重包装后总重量
第 N 份价格    = 第 N 份重量 × 重包装后单价
```

### 核心原则

> **总售价保持不变**，仅根据重新分装后的重量重新分配单价。

### 计算示例（4 颗分 3 份）

| 输入项 | 数值 |
|--------|------|
| 4 颗每斤单价 | 12.00 元/斤 |
| 4 颗总重量 | 10.00 斤 |
| **4 颗总价格** | **120.00 元** |

| 分装份数 | 重量 | 对应价格 |
|---------|------|---------|
| 第 1 份 | 3.00 斤 | 40.00 元 |
| 第 2 份 | 3.00 斤 | 40.00 元 |
| 第 3 份 | 3.00 斤 | 40.00 元 |
| **合计** | **9.00 斤** | **重包装后单价 ¥13.33/斤** |

## 🚀 快速开始

### 环境准备

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版）
2. 一个微信小程序 AppID（可在 [微信公众平台](https://mp.weixin.qq.com/) 注册获取）

### 运行项目

```bash
# 1. 克隆仓库
git clone https://github.com/sheyongguang/UnpackingCalculator.git

# 2. 用微信开发者工具「导入项目」
#    目录选择克隆下来的文件夹
```

### 配置 AppID

打开 `project.config.json`，将 `appid` 字段替换为你自己的小程序 AppID：

```json
{
  "appid": "your-appid-here"
}
```

> 💡 仓库中的 `appid` 为占位符 `touristappid`，导入后请替换为你自己的 AppID 才能正常上传发布。
